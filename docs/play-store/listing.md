## Full description

BQ Sqwad Data Receipt helps make mobile data usage easier to understand and manage.

Keep data-bundle details organised, review installed applications, estimate data costs and prepare shareable Data Receipts. Optional tools provide budget calculations, bundle planning and a floating Live Cost Bubble that displays total device data transferred during an active session.

**Key features**
- Add and manage mobile data bundles.
- Estimate data costs using bundle details and available Android usage statistics.
- View applications installed on the device.
- Use the Live Cost Bubble to monitor total device data transferred during an active session.
- Create and share Data Receipts.
- Use data calculators, budget tools and bundle-planning utilities.
- Receive optional reminders and notifications.

**Privacy and permissions**
Some features require Android Usage Access, installed-app visibility, notifications or optional display-over-other-apps permission. Usage statistics, installed-app information and bundle details are processed locally by the Application. Google AdMob may process advertising and device information as described in the Privacy Policy.

Designed and developed by BQ Sqwad Technologies.
