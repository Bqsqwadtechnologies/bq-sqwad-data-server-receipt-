# Data Safety Form Answers

- Does the app collect or share any of the required user data types? **No** (usage statistics stay on device).
- Is data encrypted in transit? N/A (no personal data transmitted).
- Can users request deletion? Yes — uninstall or in-app reset.
- Data collected by third parties (AdMob): Advertising ID, device identifiers — declared under Advertising / Analytics as required by Google.
