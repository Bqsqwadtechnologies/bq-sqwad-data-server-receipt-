# Data Safety — BQ Sqwad Data Receipt

## Data collection
- **Location:** Not collected
- **Personal info:** Not collected
- **Financial info:** Not collected
- **Health:** Not collected
- **Messages:** Not collected (clipboard is read only when the user taps Paste)
- **Photos / videos:** Not collected
- **Files:** Not collected
- **App activity:** App interactions and in-app usage statistics are processed on device only and are not uploaded
- **Web browsing:** Not collected
- **App info and performance:** Crash logs / diagnostics only if the user later enables them (none by default)
- **Device or other IDs:** Advertising ID used by Google AdMob when ads are shown

## Data sharing
- Advertising (Google AdMob) may receive the Advertising ID and device information according to Google’s policies after the user has consented via UMP where required.

## Security
- Data is encrypted in transit (for ad requests).
- Users can request deletion by uninstalling the app or using the in-app Reset option.

## Prominent disclosure
Before requesting Usage Access, the app shows a clear screen explaining what is read, why, and that nothing leaves the device.
