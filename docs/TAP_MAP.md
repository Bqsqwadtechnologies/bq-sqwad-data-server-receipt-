# Tap Map — BQ Sqwad Data Receipt

Every tappable element and its action. Updated as features are connected.

## Home
| Element | Action |
|---------|--------|
| Hero spend card | Open Spend Details |
| Runway card | Open Runway Details |
| Top spender row | Open App Detail |
| See all | Navigate to Apps tab |
| Setup checklist row | Deep-link to system permission or in-app screen |
| Period chip | Open period bottom sheet |
| Overflow menu items | Share receipt / Calibrate / Help / About |
| Grant access card | Open Usage Access settings |
| Tip card | Next tip / long-press share |
